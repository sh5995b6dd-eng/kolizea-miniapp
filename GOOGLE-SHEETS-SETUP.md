# Подключение KOLIZEA GROUP к Google Sheets

## 1. Создайте таблицу
1. Откройте https://sheets.new и создайте таблицу.
2. В меню **Расширения → Apps Script** откройте редактор.
3. Замените содержимое файла Code.gs кодом из [google-apps-script/Code.gs](https://github.com/sh5995b6dd-eng/kolizea-miniapp/blob/main/google-apps-script/Code.gs).
4. Сохраните проект.
5. В выпадающем списке функций выберите `setup` и нажмите **Выполнить**. Разрешите доступ к своей таблице. Создастся вкладка «Задачи» с примером строки.

## 2. Опубликуйте API
1. В Apps Script нажмите **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я**.
4. У кого есть доступ: **Все**.
5. Нажмите **Развернуть**, пройдите авторизацию и скопируйте URL, который заканчивается на `/exec`.

API сейчас работает только на чтение заданий. Публичная запись отключена специально, чтобы посторонние не могли добавлять или менять строки. Не размещайте в таблице пароли, секреты, банковские данные или личные документы.

## 3. Подключение сайта
Отправьте URL веб-приложения `.../exec` в чат. После этого его можно безопасно подставить в клиентский код сайта и заменить чтение Appwrite на Google Apps Script. Не отправляйте OAuth-токены, пароли или секретные ключи.
